修改后如何联动

  1. 设计师在原规范 HTML 中调整样式或说明，由 AI 对照修改内容，协调原契约与共享实现。
  2. 继续通过原组件同步入口更新规范表、变体决策、本地调用资料和依赖记录；样板从这些来源重新生成。
  3. 共享规范更新后，维护中的父组件预览和新调用使用更新来源，并按实际影响复核；已交付页面保留原固定版本。

工程维护入口：npm run component:sync；影响范围：npm run impact -- button。同步脚本不自动判断设计意图或替代父组件验收。

加载宽度的适用范围

Processing宽度固定属于该账户中心固定宽度场景，不是全部自适应Button的默认保宽规则。当前本地调用尚未实现该场景的宽度/多行/省略和提示，不宣称支持，也不把所有按钮改成固定宽。
