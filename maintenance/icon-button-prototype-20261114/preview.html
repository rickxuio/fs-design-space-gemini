修改后如何同步

  1. 在原HTML维护规范，由AI理解差异并协调契约和共享实现。
  2. 继续原component:sync / component:watch，同步片段、选型、依赖和本样板。
  3. 复核受影响父组件；旧页面继续使用其固定版本。迁移中间检查在隔离副本完成，稳定后再正式同步。

影响范围沿用 npm run impact -- icon-button。

来源差异与调用边界

  • S为20px热区/14px图标，XS为24px热区/12px图标，不按字面顺序缩放。S源稿声明6px内距，与已实现的3px居中内距不同，保留现有明确适配。
  • 筛选来源有Default和Checked，没有独立Hover身份；现有Hover沿用本地规范，不伪称本轮新增MG原子。
  • 本轮核对新MG的有限尺寸、背景和显式颜色声明；官方SVG轮廓仍沿原来源，不作整族或逐像素批准。
  • 原稿置顶、日历、分享、小i等额外图标没有因此开放。工具提示是独立宿主能力，不因来源说明就新增tooltip接口。
  • aria-label始终按实际操作提供。默认颜色以具体图标为准，不能将Gray3套给筛选和S关闭；不使用页面filter修改颜色。
