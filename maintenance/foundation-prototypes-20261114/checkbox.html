Checkbox 复选框

复选框组件，两种尺寸（大 18px / 小 14px），六种状态（默认未选 / 悬停 / 选中 / 半选 / 禁用 / 选中且禁用）。方块视觉由 icons/icon-checkbox-*.svg SVG资源按状态切换，不使用浏览器原生 input 默认样式。

样式与调用状态 · 变体决策 · 依赖与维护 · 调用边界

样式与调用状态

固定版本：89cd38bf7136。当前可调用 2 个变体；工程状态 current。来源核对与视觉确认分别保留；调用范围以本版本登记为准，不增加视觉批准。

变体决策

按原规范的具体场景逐项判断，先排除禁用条件，再在候选中核对宿主、内容与调用范围；资料不足保留待确认。设计参考不开放调用。展示与本地AI索引使用同一份规则。

大号 lg普通大号18px选项；普通多选同组≥2，协议等布尔开关可单项。候选 · 按登记接口调用。lg可调用；仍须匹配场景
下拉/表格行/筛选侧栏等密集容器 → 用小号。不用 · 不用此变体。lg此场景不用该变体
小号 sm密集14px选项或已核实的表单/协议宿主；普通多选同组≥2，协议等布尔开关可单项。候选 · 按登记接口调用。sm可调用；仍须匹配场景
来源明确18px的商品/其他选项行；不得为压缩空间擅自改小。不用 · 不用此变体。sm此场景不用该变体

修改后如何同步

  1. 在原规范 HTML 维护，由 AI 理解差异并协调原契约及共享实现。
  2. 继续原 component:sync / component:watch，同步调用、选型、依赖和本页。
  3. 检查受影响的真实父组件；已交付页面继续使用固定版本。

影响范围：npm run impact -- checkbox

调用边界

普通同组复选应≥2且不互斥；协议/记住密码/保持登录等明确布尔开关可单项。按宿主来源选lg18/14文字或sm14/13文字。保留原生input，不复制宿主受控标记为独立Checkbox。

当前未开放：host-marker-without-label、indeterminate-state-edit、disabled-indeterminate、mobile、browser-keyboard-acceptance-pending、linked-text-slot
