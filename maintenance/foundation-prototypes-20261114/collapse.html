Collapse 折叠面板

折叠面板组件，一个组件四种类型：基础分割型（设置/信息组，右侧 Always Active 绿字或 toggle 开关，折叠指示器用 icon-collapse-plus/minus）/ 行内编辑型（账户信息，预览态⇄编辑态，复用 Input + Button）/ 数据预览型（订单行展开 Order Preview，两种形态：含/不含 Pickup Order 标签）/ 特征导引型（产品特征列表，默认展开首条，前导图标，联动右侧媒体，鼠标悬浮展开）。默认手风琴单开；仅 split 可通过 data-collapse-mode=multiple 显式多开。规范 v2.0。

  2. 继续原 component:sync / component:watch，同步调用、选型、依赖和本页。

调用边界

按原件区分 Cookies、FAQ、账户编辑、订单预览、特征导引和地图联动。当前 split/feature/faq/data-preview 按各自来源可调用；参考形态不得套现有类名冒充。默认单项展开；媒体/地图/业务保存需真实宿主实现。 已有FAQ原件可用faq组合：首中尾随行数确定，原箭头与底线状态联动，默认全部收起，单项展开。 List折叠详情先转引本组件data-preview，仅账户订单快照适用，不能冒充FAQ或任意树表。 Current five-variant closure 20261115: only supported exact source examples and publication decisions permit local calls. Earlier preview-only or placeholder descriptions are historical; PC geometry and host boundaries remain explicit.

当前未开放：toggle-aside-canonical-call、feature-media-synchronization、invented-change-event、mobile、v3-faq-atom-six-variants、map-synchronization
