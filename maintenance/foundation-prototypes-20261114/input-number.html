InputNumber 数字输入框

规范明确正整数和有界范围，包含按钮、上下键、Tab、粘贴/焦点行为。沿用现有正整数配置与运行时；价格计算等业务归宿主。

修改后如何同步

  1. 在原规范 HTML 维护，由 AI 理解差异并协调原契约及共享实现。
  2. 继续原 component:sync / component:watch，同步调用、选型、依赖和本页。
  3. 检查受影响的真实父组件；已交付页面继续使用固定版本。

影响范围：npm run impact -- input-number

调用边界

outline-sm用于紧凑数量，outline-lg用于白底常规数量，filled-lg用于灰底表单。取实际默认实例；仅在初始化前替换正整数配置，不通过新增CSS造尺寸。 按relations.variantDecisions的具体场景选型；最终资格读同版catalog，未开放项不自动调用。当前MG核对状态见prototypeRollout，不将既有来源冒称本次在线核对。

当前未开放：negative、decimal、unbounded、dynamic-insertion、dynamic-range-change、business-price-recalculation、mobile
