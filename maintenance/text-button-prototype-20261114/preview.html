修改后如何同步

  1. 设计师修改原规范 HTML；由 AI 理解差异，协调原契约和共享实现。
  2. 继续运行原 component:sync / component:watch，同步规范表、本地片段、选型资料与依赖；本样板随同一次同步重建。
  3. 共享样式更新后复核实际影响的父组件；原有已交付页面保留固定资源版本。

影响范围沿用 npm run impact -- text-button。
