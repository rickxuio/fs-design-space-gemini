# 新版组件维护来源

本目录只维护组件规范、契约、变体映射、共享资源和父子依赖。页面任务统一读取项目根目录的 [AGENTS.md](../AGENTS.md)，不在本目录建立另一套页面流程。

修改组件时先读相关原契约、真实 Preview、变体决策与依赖；保留真实来源及调用边界。HTML 改动由 AI 理解差异并协调原契约和共享实现，再从项目根目录运行 `npm run component:sync`。源验证和对应有限工程测试必须真实通过；不伪造验收，不覆盖已交付页面版本。

组件目录的少量历史路径只保留被组件直接引用的 MG 原始证据、素材与工程日志，不提供页面记录、上下文或登记机制。
