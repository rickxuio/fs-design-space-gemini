⚠️ 硬规则：父项只展开，叶子项唯一选中
描述原文
一级父项点击只展开或收起，不得进入 selected；同一组件内只展开一个父项。一级或二级叶子项点击后必须成为唯一 selected，二级叶子的所属父项保持展开。
AI 解析（写入契约 JSON 的字段）
parent.click = toggleOnly
parent.selected = false
expandedParent.max = 1
leaf.selected.max = 1
childSelection.keepParentExpanded = true
⚠️ 硬规则：搜索只派发事件，不实现隐式过滤
描述原文
multi-level-search 必须使用真实 input type="search"。输入时只派发 ds:menu-navigation-search；不得在组件内部实现过滤、零结果、自动展开或关键词高亮。
AI 解析（写入契约 JSON 的字段）
search.element = input[type=search]
search.event = ds:menu-navigation-search
search.internalFilter = false
search.autoExpand = false
search.highlight = false
⚠️ 硬规则：仅 PC，公共头部不 sticky
描述原文
标准变体只允许 288px/250px，sticky top 为 16px；public-header 只允许 240px 且不得 sticky。M 端在补充代码并明确要求前保持 deferred。
AI 解析（写入契约 JSON 的字段）
standard.width = [288,250]
standard.stickyTop = 16
publicHeader.width = 240
publicHeader.sticky = false
mobile.status = deferred
⚠️ 硬规则：选中指示线与文字等宽
描述原文
当前普通叶子项 Hover/Pressed/Selected 的红线锚定 item-label，与文字等宽；一级 disclosure 父项各状态不显示选中线。
AI 解析（写入契约 JSON 的字段）
leaf.indicator = hover | pressed | selected
parent.indicator = false
indicator.anchor = itemLabel
⚠️ 硬规则：标准侧栏灰色底留白
描述原文
当前普通菜单灰底上/下20px、左16px；历史共享资源左15px保留。public-header另行核对。
AI 解析（写入契约 JSON 的字段）
current.standard.gutter = [20,0,20,16]
legacy.leftGutter = 15
