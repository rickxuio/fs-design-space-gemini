描述原文
复选框方块使用 icons/icon-checkbox-*.svg 的12个来源SVG（两尺寸×六态），不使用浏览器默认勾选外观或自行绘制图形。独立控件保留隐藏的原生 input type="checkbox"，负责键盘、表单与checked/disabled语义；原子box负责FS外观。宿主受控标记适配仅按已登记范围调用，不叠加独立input事件。同组尺寸统一；实际尺寸与文案配置优先跟随已核实宿主来源。 原生current根按原件适应宽高，不拉满父列形成额外空白热区；104/95px仅为原件示例宽。
AI 解析（写入契约 JSON 的字段）
relations.iconDependencies：12个已登记来源SVG，存在性受检。
relations.notes：原生input负责独立控制；宿主受控标记不叠加原生事件。
relations.variantSelectionRules：一般选项默认lg，密集及来源已核实的14px宿主可用sm，同组尺寸统一。
