⚠️ 硬规则：嵌入式标准产品卡片仅用于搜索结果页
描述原文
embedded.product-standard 仅允许用于搜索结果页，普通页面不得使用。普通页面的图上文下卡片优先核对 spliced.vertical.single-event 的契约与 Preview；只有参考内容能够填入其必需区域时才使用，不得编造内容或删减组件结构。
AI 解析（写入契约 JSON 的字段）
本地组件映射选择 embedded.product-standard 前，必须有页面为搜索结果页的可见证据并在本地模块映射中说明；普通页面优先核对 spliced.vertical.single-event，内容不适配时继续映射其他真实变体。
⚠️ 硬规则：卡片边框 ↔ Section 背景色
描述原文
卡片在白底时，必须要有描边；在灰底时，不能有描边。多个通栏卡片上下排列时，图左文右 / 文左图右要交替。
AI 解析（写入契约 JSON 的字段）
relations.parentContext[
  "page-section--white"
].resultingClass
  = "ds-card--bordered"

relations.parentContext[
  "page-section--gray"
].resultingClass
  = "ds-card--no-border"
⚠️ 硬规则：横向图文卡片的操作入口统一使用黑色 TextButton
描述原文
所有横向图文卡片的操作入口统一使用黑色 TextButton（inline-black）；不使用实心或描边 Button。只有嵌入式产品卡片的 Add 操作复用 Button 家族的 Cart 产品卡加购原子（不是普通 filled-red Button）。
AI 解析（写入契约 JSON 的字段）
relations.notes +=
  "横向图文 Card：操作入口统一使用黑色 TextButton；嵌入式产品卡 Add 才使用 filled-red Button"
⚠️ 硬规则：竖向单事件卡片的操作槽仅允许 TextButton
描述原文
竖向单事件 Card 的 ds-card__link 必须复用真实 TextButton Preview DOM，包含 ds-text-btn__text；inline 变体还必须包含 ds-text-btn__icon。不允许放入实心或描边 Button。横向图文 Card 同样只允许黑色 TextButton。
AI 解析（写入契约 JSON 的字段）
relations.notes +=
  "竖向单事件 Card 的 link slot 仅允许 TextButton Preview 完整 DOM；inline 包含 text 与 icon；横向图文 Card 同样只允许黑色 TextButton"
⚠️ 硬规则：横向卡片标题到正文固定 12px
描述原文
横向 Card 的 ds-card__desc 顶部间距必须使用 spacing.md（12px）。
AI 解析（写入契约 JSON 的字段）
relations.notes +=
  "horizontal / horizontal-reverse 标题到正文使用 spacing.md = 12px"
