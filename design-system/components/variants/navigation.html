⚠️ 硬规则：Rule 0（最高优先级）：Header / Footer 逐字使用
描述原文
首次生成时，header/footer 逐字使用。
• Logo 始终 icon-logo-fs.svg，不能换
• 导航项固定：All Products / Solutions / Services / Resources / Contact Us
• 右侧 actions 固定：搜索 / 购物车 / 账户，不能增删（US036747原件顺序）
• 禁止在 header 内加红色 CTA
• 源站/竞品/第三方页面的 header 一律忽略不带入
• 唯一允许的定制：文档化的 data-props
