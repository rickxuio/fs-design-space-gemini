⚠️ 硬规则：图标卡片自身表面与父板块分开
描述原文
当前居中/居左单事件调用保持原件Gray9 #FAFBFB、无描边、8px圆角。可放在白色或灰色板块中；不能按section颜色自动换白底或添加描边。真实白底、跳转及折叠的未开放范围仍保留。图标、内容槽与状态按各自实际调用边界核对。
AI 解析（写入契约 JSON 的字段）
backgroundBorderRules[].variants -> selected native gray Card class; section.surface does not choose the Card surface.
⚠️ 硬规则：跳转型蓝色链接必须用 &lt;p&gt; 标签
描述原文
跳转型卡片的蓝色链接文字必须用 <p class="ds-icon-card__blue-link">，不能用 <a> 或 <span>。
AI 解析（写入契约 JSON 的字段）
relations.mandatoryTagRule = {
  cls: "ds-icon-card__blue-link",
  requiredTag: "p"
}
⚠️ 硬规则：单事件图标卡片文字按钮必须保留完整 TextButton 结构
描述原文
ds-icon-card__link 内必须使用真实 TextButton Preview DOM，并包含 ds-text-btn__text 与 inline 变体要求的 ds-text-btn__icon。禁止放入实心/描边 Button，也禁止用 span 或纯文字模拟文字按钮。
AI 解析（写入契约 JSON 的字段）
relations.notes +=
  "IconCard 的 link slot 必须复用 TextButton Preview 完整 DOM，不得简化嵌套子组件"
