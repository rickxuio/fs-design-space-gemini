⚠️ 硬规则：Tab 数量必须与页面 section 锚点数量一致
描述原文
AnchorNav 的 tab 项数量必须和页面实际的 section 锚点数量匹配。新增/删减页面 section 时要同步检查 AnchorNav 的 tab 列表。

  reason: "每个 tab 对应页面下方一个 page-section 的 id，用于锚点跳转；tab 数量与 section 数量应一致"
}
⚠️ 硬规则：保留 Preview 的 div 标签并允许页面补充锚点跳转
描述原文
AnchorNav 的 tab 必须保留 Preview 的 div.ds-anchor-nav__tab 结构与组件样式。参考页面确有锚点跳转且 本地模块映射记录目标 section 时，页面 JS 可补充滚动定位与选中态同步，此用法仍算直接调用。不得将 tab 改为 a；文字不得出现浏览器默认下划线，激活态红色底边线必须保留。
AI 解析（写入契约 JSON 的字段）
保留 Preview 的 div.ds-anchor-nav__tab 与既有选中态；仅在来源有可见跳转证据且本地模块映射记录目标 section 时，允许页面 JS 补充滚动定位/选中态同步并标为直接调用；禁止 a 标签和文字默认下划线，保留激活态底边线。
⚠️ 硬规则：滚动时必须吸顶并保持可见
描述原文
AnchorNav 在 Banner 之后、页面主内容区之前；页面向下滚动后必须以 position: sticky、top: 0 固定在视口顶部。导航需保持可见并位于页面内容之上；锚点跳转落点不得被 56px 导航遮挡。
AI 解析（写入契约 JSON 的字段）
ds-anchor-nav 必须由组件 CSS 实现 position: sticky; top: 0，并具有足够层级；页面滚动后导航顶边贴合视口顶边，锚点目标内容在导航下方可见。
