⚠️ 硬规则：激活态必须同时具备 class + indicator 元素
描述原文
Standard/Capsule 的激活态必须同时加 ds-tab__item--active class 与内部 ds-tab__indicator 元素，二者缺一不可。只加 class 不加 indicator 会缺少红色/白底视觉反馈。居中对齐加 ds-tab--center。
AI 解析（写入契约 JSON 的字段）
relations.structuralRequirement = {
  rule: "激活态必须同时具备 ds-tab__item--active class 与内部 ds-tab__indicator 元素；只加 class 不加 indicator 会导致缺少红色/白底视觉反馈",
  appliesTo: ["standard","capsule"]
}

states[1].styleOverrides.structure
  = "ds-tab__item--active
    + 内部 ds-tab__indicator"
⚠️ 硬规则：Tab选项清除原生外观；居左/居中按原件选择
描述原文
ds-tab__item必须保留完整内层结构并清除原生button外观。常规Tab按对应原件选择居左或居中，不能因选项未占满而强制居中；居中原件使用ds-tab--center、内容适应宽度，底线覆盖自身内容区域。
AI 解析（写入契约 JSON 的字段）
alignment follows source layout; centered regular Tab uses intrinsic content width. Available spare width does not override left-aligned source.
⚠️ 硬规则：可见 Tab 必须支持单击与键盘切换，禁止静态假控件
描述原文
只要 Tab 在视觉上呈现为可切换，每个非禁用项就必须可单击；不得实现为无监听器的静态 div。当前页选中态切换不得跳转、刷新或改变 location.href、hash、滚动位置；切换后必须保持唯一 ds-tab__item--active、唯一 ds-tab__indicator、唯一 aria-selected="true"，并采用 roving tabindex。键盘必须支持 ArrowLeft/ArrowRight 循环、Home/End、Enter/Space。
AI 解析（写入契约 JSON 的字段）
interaction = {
  click: "全部非禁用项可切换",
  keyboard: ["ArrowLeft", "ArrowRight", "Home", "End", "Enter", "Space"],
  state: "唯一 active + indicator + aria-selected=true",
  focus: "roving tabindex: active=0, others=-1",
  currentPageSelection: "URL/hash/scroll 均保持不变"
}

禁止：静态 div、因本地路由缺失而整组 aria-disabled
