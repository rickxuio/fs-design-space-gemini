⚠️ 硬规则：选择器语义与键盘闭环
描述原文
触发器必须为 button[role=combobox]，选项必须使用 role=option；展开、选择、禁用、焦点与键盘状态必须同步 ARIA。
AI 解析（写入契约 JSON 的字段）
trigger.role = combobox
trigger.ariaExpanded ↔ panel.hidden
option.ariaSelected ↔ visual selected
Arrow/Home/End/Enter/Space/Escape supported
⚠️ 硬规则：PC-only 与 Dropdown 分界
描述原文
本版本只实现 PC；Select 用于值选择，Dropdown 只用于动作或导航菜单，两者不得互相替代。
AI 解析（写入契约 JSON 的字段）
platform = desktop
Select = value input
Dropdown = action/navigation menu
