变体决策

按已投喂 Tag v2.5 原始 HTML 选择六种实现；尺寸、颜色和状态均来自源码证据。

类型 变体决策（什么场景用）
纯文字状态 status-text 用：无底无边框地显示 New、Hot 等短状态，使用 12/20 或 14/22 两档。
不用：需要色块容器时改用 semantic；需要交互时改用 selectable。
并列元数据 metadata 用：并列展示 Education | United States 等同层级元数据。
不用：单个状态或可操作筛选条件。
20px 语义标签 semantic 用：展示 Individual、Split Order、Pickup Order、New、Hot、Limited Offer 等业务语义。
不用：需要选择/取消选择时改用 selectable 或 filter。
28px 可选择胶囊 selectable 用：Router 等纯文字属性需要 default、hover、checked 反馈。
不用：带前缀、值、关闭图标的条件改用 filter。
28px 复合筛选 filter 用：Industry: K-12 Education 等前缀、值和关闭图标组成的筛选条件。
不用：纯文字属性改用 selectable。
FEATURED 图标标签 featured 用：仅用于 FEATURED 精选标识。
不用：普通状态、属性、筛选或任意自定义图标标签。
⚠️ 硬规则： 只实现已投喂 Tag，宽度由内容决定

👤 描述原文

只允许使用 status-text、metadata、semantic、selectable、filter、featured 六类 Tag；商品/服务卡片、SKU 和模块选择器不属于 Tag。禁止使用 Figma specimen 固定宽度；单枚 Tag 随内容自适应并保持单行，受限时只省略文字，多枚标签用 ds-tag-group 换行。Individual、Split Order、Pickup Order 必须复用 icon-info.svg 并继承标签语义色；New、Hot、Limited Offer 不显示图标。
