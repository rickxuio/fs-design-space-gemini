Checkbox 复选框 v1.0

复选框组件 — 两种尺寸（大 18px / 小 14px），五种状态（默认 / 悬停 / 选中 / 半选 / 禁用）

变体决策

两种尺寸的选择规则。同一组复选框列表内尺寸必须统一，不得大小混用。被 Dropdown 的多选/分组/Filter 变体嵌套使用（默认 sm）。图标依赖登记在下方依赖汇总表的图标列。

类型 变体决策（什么场景用）
大号 lg 用：默认尺寸，独立选项、表单勾选项。
不用：下拉/表格行/筛选侧栏等密集容器 → 用小号。
小号 sm 用：下拉菜单选项、表格行内、筛选侧栏等密集列表，空间紧张时。
不用：普通表单/独立选项 → 用大号。
⚠️ 硬规则： 方块必须用 icon-checkbox-* 位图，组内尺寸统一

👤 描述原文

复选框方块必须使用 icons/icon-checkbox-* 位图（共 12 个），禁止用浏览器原生 input 默认样式或手写内联 SVG。默认用 lg（方块 18px），仅下拉/表格行/筛选侧栏等密集容器空间紧张时用 sm（14px）；同一组复选框列表内尺寸必须统一，不得大小混用。
