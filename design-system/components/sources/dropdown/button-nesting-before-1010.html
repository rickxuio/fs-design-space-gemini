变体决策

六种变体共享 trigger/panel 骨架；可选插槽和嵌套组件仅按契约的 componentDependencies 填写。

类型 变体决策（什么场景用）
基础下拉 用：只需触发器与选项列表。
不用：选项较多需检索 → 用带搜索。
带搜索 用：列表需要搜索入口。
不用：无需搜索 → 用基础下拉。
多选 Checkbox 用：需要从选项中多选。
不用：只允许单选时不用；改用基础下拉或相应 Select 单选变体。
分组 用：按组组织选项，可提供确认/取消操作。
不用：选项无需分组且没有底部操作时用基础下拉；需要搜索时选择带搜索。
Filter 筛选 用：使用胶囊触发器的多组筛选。
不用：不是多组筛选、也不需要胶囊触发器时不用；单一选项选择用基础下拉。
品牌选择 用：小尺寸品牌选择且需搜索。
不用：不是品牌选择或无需该小尺寸搜索结构时不用；一般检索选择用带搜索。
⚠️ 硬规则：无
