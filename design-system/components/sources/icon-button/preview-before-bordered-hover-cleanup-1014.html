IconButton 图标按钮 v1.0

仅包含图标的按钮 — 用于关闭、搜索、编辑、下载等操作，支持带边框和无边框两种类型

变体决策

类型、尺寸范围和互斥规则均以组件契约为准；实际图标属于图标库选择，不在嵌套子组件列登记。

类型 变体决策（什么场景用）
带边框 XL 用：40px 筛选按钮，16px 筛选图标；使用 aria-pressed 表示选中状态。
不用：搜索与其他工具操作不能仅因需要边框就套此变体。
无边框 L 用：工具栏、列表行等紧凑操作，容器可容纳 L 尺寸。
不用：更紧凑的容器 → 用 M/S/XS；需要显式边界 → 用带边框 XL。
无边框 M 用：常规工具栏或列表行图标操作，使用 M 尺寸。
不用：主触点或更大点击区 → 用 L/XL；超紧凑区域 → 用 S/XS。
无边框 S 用：紧凑列表行或密集工具区，使用 S 尺寸。
不用：需要常规点击区 → 用 M/L。
无边框 XS 用：只在极端紧凑的辅助操作中使用 XS。
不用：常规工具栏、主操作或需要较大点击区 → 用 S/M/L。
筛选XL已选中 用：筛选条件已启用时，40px容器、16px筛选图标；aria-pressed=true。
不用：尚未启用筛选条件时用 bordered-xl。
⚠️ 硬规则：无
