评分 Rate v1.0

单值评分展示、1–5 星输入与精简评分汇总；支持 16px、20px、24px 三档完整星。

变体决策

先区分单值展示、用户评分输入和精简聚合；尺寸是 display/input 的正交修饰，不复制设计画板的绝对坐标。

类型 变体决策（什么场景用）
评分展示 display 用：单个既有评分只读展示，可带数值或业务已提供的文案。
不用：用户需要修改评分时使用 input；需要数量分布时使用 summary。
评分输入 input 用：当前页面内选择、修改或 Clear 清除 1–5 星评分。
不用：只读结果使用 display；商品配置或套餐选择使用 OptionSelector。
精简评分汇总 summary 用：仅展示综合分值、评论总数和 5→1 星数量分布。
不用：包含评论媒体、标签筛选或评论列表联动时使用 Comment/rating-summary。
⚠️ 硬规则： 固定完整五星，并区分评分输入与评论聚合

👤 描述原文

Rate 固定为 5 颗完整星，不支持半星。input 必须使用 radiogroup + button[role=radio]，支持 hover 预览、点击提交、Clear 重置和键盘操作；display/summary 只读。包含评论媒体、分类筛选或评论列表联动时必须改用 Comment/rating-summary。

🤖 AI 解析（写入契约 JSON 的字段）

scale = [1, 2, 3, 4, 5]
halfStar = false
variants = ["display", "input", "summary"]
input = { sizes: ["md", "lg"], semantics: "radiogroup", clear: true }
summary = { media: false, filters: false, commentList: false }
