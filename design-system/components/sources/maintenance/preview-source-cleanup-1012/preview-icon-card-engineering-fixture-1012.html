IconCard 图标卡片 v1.0

以图标代替图片的卡片组件，支持居中/居左布局、白底/灰底、含描边/无描边、单事件/多事件/跳转型

变体决策

每种图标卡片类型：什么场景用 → 用了哪个子组件 → 这个依赖是否核实过。

类型 变体决策（什么场景用）
居中 · 单事件 用：来源为居中布局；图标+标题即可，短描述、bullets 和普通操作链接按来源可选；bullets 在内容区左对齐。
不用：来源为图标居左 → 比较居左变体；有可见 bullets 折叠控件 → 比较居中折叠型；纯蓝色链接列表不属于此变体。
居中 · 多事件折叠展开 用：居中布局下 bullets 列表超长（超过容器高度），需要折叠+See more/See less 切换。
不用：来源没有可见展开/收起行为 → 用居中·单事件；不能仅按 bullets 数量新增折叠。
居左 · 单事件 用：来源为图标居左、内容居右；图标+标题必需，描述、bullets、普通操作链接按来源可选。
不用：只有标题+一组蓝色链接列表、无描述无bullets → 用居左·跳转型。
居左 · 跳转型 用：标题+一组蓝色链接列表（ds-icon-card__blue-links），无描述无bullets——纯跳转入口。
不用：只要出现描述/bullets → 用居左·单事件。
居左 · 多事件折叠展开 用：居左布局下 bullets 列表超长，需要折叠+See more/See less 切换。
不用：来源没有可见展开/收起行为 → 用居左·单事件；不能仅按 bullets 数量新增折叠。
⚠️ 硬规则： 图标卡片边框 ↔ Section 背景色

👤 描述原文

图标卡片在白底 section 时，必须有描边；在灰底 section 时，不能有描边。背景色始终用 bg-white。图标直接暴露，不加圆形/圆角背景容器。宽度由父容器（grid/flex）控制，不手动设固定 width。

🤖 AI 解析（写入契约 JSON 的字段）

relations.parentContext[
  "page-section--white"
].resultingClass
  = "ds-icon-card--bg-white ds-icon-card--bordered"

relations.parentContext[
  "page-section--gray"
].resultingClass
  = "ds-icon-card--bg-white"
⚠️ 硬规则： 跳转型蓝色链接必须用 <p> 标签

👤 描述原文

跳转型卡片的蓝色链接文字必须用 <p class="ds-icon-card__blue-link">，不能用 <a> 或 <span>。

🤖 AI 解析（写入契约 JSON 的字段）

relations.mandatoryTagRule = {
  cls: "ds-icon-card__blue-link",
  requiredTag: "p"
}
⚠️ 硬规则： 单事件图标卡片文字按钮必须保留完整 TextButton 结构

👤 描述原文

ds-icon-card__link 内必须使用真实 TextButton Preview DOM，并包含 ds-text-btn__text 与 inline 变体要求的 ds-text-btn__icon。禁止放入实心/描边 Button，也禁止用 span 或纯文字模拟文字按钮。

🤖 AI 解析（写入契约 JSON 的字段）

relations.notes +=
  "IconCard 的 link slot 必须复用 TextButton Preview 完整 DOM，不得简化嵌套子组件"
