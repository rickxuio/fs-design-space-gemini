Carousel 走马灯 v1.2.2608A

轮播组件 — 圆形实心导航按钮（Prev / Next）+ 分页指示器（Dots），含首页 Banner 场景

变体决策

Carousel 含四个切换按钮规格（实心 XL/L/S、描边 M）、Light/Dark 配色、标准/长条激活分页、叠加/版心两侧布局及首页 Banner；首页场景固定 Dark + solid-xl + 首页专属分段进度轨 + 叠加。

类型 变体决策（什么场景用）
配色 · Light（浅色） 用：浅色/白色背景上的轮播。
不用：深色 Banner 背景 → 用 Dark 变体。
配色 · Dark（深色） 用：深色 Banner 背景上的轮播。
不用：浅色背景 → 用 Light 变体。
尺寸/外观 · 实心 XL 用：输入证据明确要求 48px 大型切换按钮；首页 Banner 固定使用。
不用：36px、20px 或白底描边规格 → 选择对应变体。
尺寸/外观 · 实心 L 用：输入证据明确要求 36px 切换按钮。
不用：不得仅凭视觉近似替代其他三个规格。
尺寸/外观 · 实心 S 用：输入证据明确要求 20px 紧凑切换按钮。
不用：常规或大型控制使用 L/XL；白底描边使用 outlined-m。
尺寸/外观 · 描边 M 用：输入证据明确要求 28px 白底描边切换按钮；Default/Hover 的 16px 箭头固定使用 color.gray-2（#4B4B4D）。
不用：实心圆形控制使用 XL/L/S。
分页 · 长条激活 用：明确要求长条激活分页；7 项为 1 条 + 6 点。
不用：普通轮播（激活态 20×8px）。
布局 · 叠加型 用：按钮直接叠加在轮播主体上，浮在图片左右边缘。
不用：需要按钮位于轮播外部的版心两侧 → 用版心两侧型。
布局 · 版心两侧 用：版心 1200px 内容配左右外侧按钮，视觉不被轮播主体遮挡。
不用：按钮要贴在轮播主体上 → 用叠加型。
场景 · 首页 Banner 用：首页多内容 Banner 有真实切换时，使用 13.125% 按钮边距与底部分页。
不用：静态 Banner、浅色背景或普通内容轮播。
⚠️ 硬规则： 版心两侧布局按钮距版心 32px + 不被裁剪

👤 描述原文

版心两侧布局时，Prev/Next 按钮放在版心外侧两边，按钮内边缘距版心左右边缘固定 32px，垂直居中。按钮必须在 .ds-carousel 的 overflow: hidden 之外，否则会被裁掉。

🤖 AI 解析（写入契约 JSON 的字段）

buttonLayouts["container-flanking"] = {
  hardConstraint: "按钮内边缘距版心左右边缘固定 32px；外层 offset = 32px + 所选按钮宽度（XL 80px、L 68px、S 52px、描边 M 60px）",
  verticalAlign: "top:50%; transform:translateY(-50%)",
  clippingWarning: "按钮必须置于 .ds-carousel 的 overflow:hidden 范围之外，否则会被裁掉；此项由 verify.js CAROUSEL_BTN 几何校验自动检测"
}
⚠️ 硬规则： 首页 Banner 场景固定使用 1920×420 基准与专属切换样式

👤 描述原文

首页 Banner 轮播必须在 .ds-carousel 根节点添加 ds-carousel--homepage-banner，并组合 Dark + solid-xl + 叠加型。场景高度固定 420px；左右切换按钮固定 48×48px、箭头 28×28px，并按 1920px 设计基准的左右 13.125% 定位；分页默认 8×8px、激活 56×8px，示例的 7 张幻灯片必须与 7 个分页按钮一一对应。普通内容轮播必须按输入证据选择四个正式按钮规格。

🤖 AI 解析（写入契约 JSON 的字段）

buttonLayouts["homepage-banner"] = {
  rootClass: "ds-carousel--homepage-banner",
  requiredCombination: ["dark", "overlaid"],
  styleProperties: { designBaseline: "1920×420px", buttonSize: "48×48px", buttonInset: "13.125%", dots: "8×8px / active 56×8px", exampleCount: 7 }
}
⚠️ 硬规则： 首页 Banner 文案内缩不得复用 Carousel 控件内缩

👤 描述原文

Homepage Carousel 的 13.125% 仅用于左右切换按钮等 Carousel 控件定位。组件 Preview 中 .homepage-banner-demo__slide 的内容内缩只属于演示布局，不能直接套用到真实页面 Banner 文案；Banner 文案位置必须依据 Banner 自身版心和参考页面内容容器单独确定。

🤖 AI 解析（写入契约 JSON 的字段）

homepageBanner.geometry = {
  controlInset: "13.125%",
  contentInset: "independent",
  previewContentPadding: "demo-only; not a live Banner content-position contract"
}
⚠️ 硬规则： 走马灯按钮/圆点永不使用红色

👤 描述原文

走马灯导航按钮和分页指示器圆点永远不使用红色（brand-red #C00000）。实心 XL/L/S 默认使用 rgba(25,25,26,0.3)，Hover 使用 rgba(25,25,26,0.5)，Disabled 使用 rgba(25,25,26,0.04) 并保留 not-allowed 光标；描边 M 使用白底、#DEE0E3 描边和 #F2F2F2 Hover。

🤖 AI 解析（写入契约 JSON 的字段）

relations.colorConstraint = {
  rule: "走马灯导航按钮和圆点永远不使用红色（brand-red）",
  severity: "硬约束，validate.js 目前未对此单独机械校验，靠 design-spec 文档约束"
}
