Option Selector 选项选择器 v1.2

OptionSelector v1.2：用于媒体、颜色、商品、价格与品牌等复合可视选择；只有圆形状态图加文字或结算说明时改用 Radio。

变体决策

四种业务变体只处理媒体、颜色、商品、价格、品牌或服务等复合可视选择；media/color/product 使用 button[role=radio] 互斥语义，service 使用 Checkbox 独立加选。只有圆形状态图加文字或结算说明的基础互斥项必须使用 Radio。

类型 变体决策（什么场景用）
图文与支付选项 media 用：模块、定制项、100 QSFP28 等图文项，或 Credit/Debit Card 等支付品牌互斥选择；根据稿件使用无框、紧凑描边或品牌 Logo 内容槽。
不用：只有圆形状态图加单行文字时使用 Radio regular；仅靠颜色辨识时使用 color；需要商品、价格等复合双行信息时使用 product；不得把 104/95/111px specimen 宽度写入生产 CSS。
颜色选项 color 用：颜色配置，色块值由业务数据传入。
不用：不得把色块作为通用状态点或 UI 图标。
商品、套餐与双行详情 product 用：具体 SKU、许可证套餐、长商品名，或商品标题与副文案/价格共同构成的复合互斥选择；选项本身必须包含商品、价格或其他业务内容。
不用：只有圆形状态图加主副文本的结算地址、配送或支付项使用 Radio bordered-detail；可独立加购服务使用 service；支付品牌 Logo-only 使用 media + payment；不得把 378px specimen 宽度固化为生产宽度。
服务勾选项 service 用：1 Year Service 等可独立加购或多选的服务；卡片布局 checkbox 位于左上，横向行位于右侧。
不用：互斥配置或许可证套餐使用 media/color/product Radio 变体。
⚠️ 硬规则： 只保留可复用选择规则，禁止复制画板

👤 描述原文

禁止复制画板、left/top/z-index、104/95/111/378px specimen 固定宽度和鼠标标注 SVG。互斥配置、套餐与支付方式使用 button[role=radio]；可独立加购服务使用原生 input[type=checkbox]。Hover 为白底深描边，Checked 为灰底深描边；disabled 必须不可操作且优先覆盖其他状态。detail/lg 与 service 内容用 __content 纵向组合标题与副文案/价格。
